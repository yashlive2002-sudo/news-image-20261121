THE WORLD TODAY: a newspaper-style front page summing up the world news of Saturday, November 21, 2026 in one 1024x1024 image, with big headlines and numbers. `main.ts` copies the pre-rendered `entry.png` (drawn from `design/front.html` by `design/render.mjs`) to `/output/entry.png`, so every run writes the same bytes with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
